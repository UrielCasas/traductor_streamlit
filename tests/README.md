# Introducción
En esta sección hay distintas pruebas realizadas como distintas longitudes de textos ingresadas y comparadas con el modelo de Google, como también pruebas de audio.

En ambos textos se realizó un análisis y conclusión del experimento realizado.

# Análisis General
En ambos experimentos donde se utilizo un **texto corto del Martín Fierro** y un **texto largo de _In My Life_** se puede observar que la longitud del texto influye en la traducción.

En textos cortos con el poco contexto cultural puede interpretarse de una manera distinta, pero en el caso de mayor contexto, hay mayor información para que el modelo pueda interpretar el sentido de las frases u oraciones.

También se demuestra que no existe una única traducción correcta, solo interpretadores o se puede mantener un significado general aunque utilicen palabras diferentes.

# Conclusión
Ambos experimentos demuestran que nuestro traductor como el traductor de Google pueden generar una traducción correcta aunque puedan presentar pequeñas diferencias en el uso de palabras.

Además, una traducción diferente no es una traducción incorrecta, ya que una expresión o un dicho puede ser traducida de manera distinta mientras respete el significado, por lo tanto, para evaluar un traductor, se debe tener en cuenta el contexto, significado, elementos culturales presentes, la naturalidad en una conversación, etc, ningún modelo puede ser considerado un ganador, cada uno puede presentar distintos resultados y alguno puede ser más adecuado que otro dependiendo del texto.
